# VIBEZ Admin Portal

The administrative dashboard for managing the VIBEZ communication platform. Built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Dashboard Overview**: Real-time system metrics and user activity.
- **User Management**: View profiles and moderate accounts.
- **Moderation**: Handle user reports and flags.
- **Audit Logs**: Track administrative actions.
- **System Settings**: Global toggles for registrations and maintenance mode.

## 🛠️ Getting Started

1.  `cd admin`
2.  `npm install`
3.  Set `NEXT_PUBLIC_API_URL` in your `.env`.
4.  `npm run dev`
