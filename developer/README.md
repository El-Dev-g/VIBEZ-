# VIBEZ Developer Hub & API Platform
**Powered by PRIGID GROUP**

Official developer platform, REST API reference, WebSocket protocol guide, interactive API Explorer, Webhook simulator, and multi-language SDKs for the VIBEZ ecosystem.

## 🚀 Features
- **Interactive REST API Reference**: Full specifications for Authentication, Channels, Messages, Statuses, Communities, Verification Badges, and System Telemetry.
- **Live API Explorer**: Test API calls directly against the live backend (`https://vibez-n5h1.onrender.com/api`) or local sandbox instances.
- **Webhook Simulator**: Test real-time event dispatching with payload inspectors and HMAC verification signatures.
- **API Key & App Registry**: Generate development credentials and configure webhook endpoints.
- **SDK Code Generator**: Ready-to-use snippets in Kotlin (Android), TypeScript/Node.js, Python, Go, and cURL.

## 🛠️ Getting Started

```bash
# Navigate to the developer portal directory
cd developer

# Install dependencies
npm install

# Run the developer portal locally on port 3002
npm run dev
```

Open [http://localhost:3002](http://localhost:3002) in your browser.
